# Local tools

- `dsh_decrypt.py` — decrypts a Kirin-Tool `.ktl` with the DTL RSA/AES scheme.
  It reads the private key from the tool repo's `Security/Constants.cs`; do not
  copy the key into this project.
- `scan_xloader.py` — quick Thumb/string/partition-table inventory for the 970
  xloader.

Run from the project root. Keep all outputs under `notes/` or `reports/`.
